# Sirio Mobile Field Guide

## Purpose

Five short, vertical guides for restaurant owners using Sirio for the first time. Each video must make one next action obvious on a phone without suggesting that the viewer needs to create an account on their own.

## Visual system

- Canvas: `#f7f1e7` (warm paper)
- Paper: `#fffdf8`
- Ink: `#29271f`
- Olive action: `#315b45`
- Copper highlight: `#b75b38`
- Teal confirmation: `#1598a6`
- Display type: Archivo Black
- UI and captions: Montserrat
- Resolution: 1080 × 1920, safe area 72 px horizontal and 120 px vertical

## Signature device language

The video is a **field guide**, not a screen recording: a phone-sized Sirio interface sits on a warm paper sheet. Copper numbered tickets identify the next step. One visible finger tap appears only at the decisive action; the interface acknowledges it in the same beat. A quick vertical push changes screens, while confirmation moments dissolve calmly into teal.

## Rules

- Keep the simulated interface generic and never show a real restaurant, account, email, password, QR or public URL.
- Headings are short and grounded. Captions stay in the lower safe area and repeat the narration exactly.
- Show a maximum of four actionable UI rows per screen.
- Do not use background music or sound effects. The Zephyr narration is the only audio.
- Do not use gradients, neon, glassmorphism, fake browser chrome or a generic dashboard grid.
